# 夯拉板（Hangla Board）

[中文](README.md) · [English](README_EN.md) · [日本語](README_JA.md)

動画クリエイター向けの Tier List（ランク表）ツールです。単独でのランク分け、クリーン録画、PNG 出力に加え、リモート出演者と使える共同編集ルームに対応します。

## 機能

- 複数画像の一括アップロードとドラッグ＆ドロップ
- 未分類トレイと各ランク間での画像移動
- 「夯、顶级、人上人、NPC、拉完了」の中国語デフォルト5段階
- ランクの追加、削除、名前変更
- ドラッグハンドルによるランク行全体の並べ替え
- 色はランク内容ではなく行位置に固定
- レインボーと赤・オレンジ・黄・白グラデーションの2テーマ
- 完成した Tier List を高解像度 PNG として書き出し
- ランキングごとに名前を付け、その名前を PNG のファイル名にも使用
- 6桁のルーム番号で複数人が同じランキングを共同編集
- オンライン参加者を表示し、ホストが最終結果をロック・再開
- ルーム内の画像、タイトル、テーマ、ランク変更を同期
- 編集操作を隠しながら未分類トレイを残すクリーン録画モード
- `Esc` キーで録画モードを終了
- 単独モードの画像は現在のページ内だけで処理されます。共同編集ルームの画像は参加者と共有するためルームストレージへアップロードされます

## クイックスタート

単独モードは `dist/index.html` を直接開いて利用できます。共同編集ルームには、データベースと画像ストレージを備えた Sites 環境へのデプロイが必要です。

1. リポジトリをダウンロード、またはクローンします。
2. ブラウザで `dist/index.html` を開きます。

開発とビルド：

```bash
npm install
npm run db:generate
npm test
```

`npm run build` でデプロイ用 Worker が生成されます。

## 使い方

1. 「上传图片」を押すか、画像をページへドロップします。
2. 未分類の画像を任意のランクへドラッグします。
3. ランク名をクリックして編集します。
4. 右側のハンドルでランク行全体を並べ替えます。
5. ボードのタイトルをクリックしてランキング名を入力します。
6. 上部メニューからカラーテーマを選択します。
7. 「导出图片」を押すと、編集用 UI を含まない完成ボードを PNG で保存できます。画像内の見出しとファイル名にはランキング名が使われます。
8. 「联机房间」を押し、ニックネームを入力してルームを作成するか、6桁の番号で参加します。
9. 招待情報をリモート出演者へ送り、全員で同じランキングを調整します。
10. 合意後、ホストが「锁定最终排名」で最終結果をロックします。必要なら再度解除できます。
11. 「干净录制」を押して録画を開始します。録画中もランク分けを続けられます。

## 現在の制限

- 単独モードは更新すると消去されます。共同編集ルームは現在のブラウザセッション内で復元されます。
- 高速ポーリングで同期します。同じ場所をほぼ同時に編集した場合は、サーバー側の新しいバージョンが優先されます。
- 動画の書き出しにはまだ対応していません。
- 現在はデスクトップブラウザと画面録画での利用を主に想定しています。
