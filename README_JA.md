# 夯拉板（Hangla Board）

[中文](README.md) · [English](README_EN.md) · [日本語](README_JA.md)

動画クリエイター向けの軽量な Tier List（ランク表）ツールです。ビルドや外部依存関係は不要で、ページを開くだけで画像の追加、ランク分け、クリーンな録画表示を利用できます。

## 機能

- 複数画像の一括アップロードとドラッグ＆ドロップ
- 未分類トレイと各ランク間での画像移動
- 「夯、顶级、人上人、NPC、拉完了」の中国語デフォルト5段階
- ランクの追加、削除、名前変更
- ドラッグハンドルによるランク行全体の並べ替え
- 色はランク内容ではなく行位置に固定
- レインボーと赤・オレンジ・黄・白グラデーションの2テーマ
- 編集操作を隠しながら未分類トレイを残すクリーン録画モード
- `Esc` キーで録画モードを終了
- 画像は現在のブラウザページ内だけで処理され、サーバーにはアップロードされません

## クイックスタート

ビルドやパッケージのインストールは不要です。

1. リポジトリをダウンロード、またはクローンします。
2. ブラウザで `dist/index.html` を開きます。

ローカル静的サーバーを使うこともできます。

```bash
python3 -m http.server 4173 --directory dist
```

その後、`http://localhost:4173` にアクセスしてください。

## 使い方

1. 「上传图片」を押すか、画像をページへドロップします。
2. 未分類の画像を任意のランクへドラッグします。
3. ランク名をクリックして編集します。
4. 右側のハンドルでランク行全体を並べ替えます。
5. 上部メニューからカラーテーマを選択します。
6. 「干净录制」を押して録画を開始します。録画中もランク分けを続けられます。

## 現在の制限

- プロジェクトの永続保存にはまだ対応していません。ページを更新すると画像と並び順は消去されます。
- 画像・動画の書き出しにはまだ対応していません。
- 現在はデスクトップブラウザと画面録画での利用を主に想定しています。
