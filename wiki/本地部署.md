# 本地部署

本地部署适合离线制作、保护素材隐私，或在自己的电脑上运行一套完整的联机房间服务。

## 环境要求

- Node.js 22.5 或更高版本
- Git
- 现代浏览器（Chrome、Edge、Firefox 或 Safari）

检查版本：

```bash
node --version
npm --version
git --version
```

## macOS / Linux

```bash
git clone https://github.com/ppxinashin/hangla-board.git
cd hangla-board
npm ci
npm run build
npm run start:node
```

打开 `http://127.0.0.1:3000`。

## Windows PowerShell

```powershell
git clone https://github.com/ppxinashin/hangla-board.git
Set-Location hangla-board
npm ci
npm run build
npm run start:node
```

打开 `http://127.0.0.1:3000`。请保持 PowerShell 窗口运行；按 `Ctrl+C` 停止服务。

## 只使用单机模式

运行过 `npm run build` 后，可以直接双击 `dist/index.html`。这种方式不启动服务器，因此不能创建联机房间，刷新后也不会保存素材。

## 让同一局域网的设备访问

macOS / Linux：

```bash
HOST=0.0.0.0 PORT=3000 npm run start:node
```

Windows PowerShell：

```powershell
$env:HOST = "0.0.0.0"
$env:PORT = "3000"
npm run start:node
```

查询电脑的局域网 IP，然后让其他设备访问 `http://电脑IP:3000`。可能需要在系统防火墙中允许 Node.js 或 TCP 3000 端口。不要把 3000 端口直接暴露到公网；公网使用请参阅 [[服务器部署]]。

## 数据位置

默认数据保存在项目根目录的 `.data`：

- `.data/tier-board.sqlite`：房间与排序数据
- `.data/files/`：联机房间上传的图片

备份时先停止服务，再完整复制 `.data`。删除 `.data` 会清空所有本地房间数据。

## 更新版本

```bash
git pull
npm ci
npm run build
```

然后重新运行 `npm run start:node`。更新前建议备份 `.data`。
