# 服务器部署

下面以 Ubuntu、Nginx 和 systemd 为例。你需要一台有公网 IP 的 Linux 服务器，以及一个可以修改 DNS 的域名。

## 1. 准备环境

安装 Git、Node.js 22.5 以上、Nginx 和 Certbot。不同 Ubuntu 版本的软件源不同，请先用 `node --version` 确认版本满足要求。

```bash
sudo apt update
sudo apt install -y git nodejs npm nginx certbot python3-certbot-nginx
node --version
```

## 2. 下载和构建

```bash
sudo git clone https://github.com/ppxinashin/hangla-board.git /opt/tier-board
cd /opt/tier-board
sudo npm ci
sudo npm run build
```

## 3. 创建运行用户和数据目录

```bash
sudo useradd --system --home-dir /opt/tier-board --shell /usr/sbin/nologin tierboard
sudo mkdir -p /var/lib/tier-board
sudo chown -R tierboard:tierboard /opt/tier-board /var/lib/tier-board
```

仓库中的 `deploy/tier-board.service` 已把程序配置为开机启动，并把数据写入 `/var/lib/tier-board`。

```bash
sudo cp /opt/tier-board/deploy/tier-board.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tier-board
curl http://127.0.0.1:3000/healthz
```

返回 `ok` 表示应用服务正常。

## 4. 配置 Nginx

复制示例前，把 `deploy/nginx-tier-board.conf` 中的 `tier.jehol-ppx.com` 替换成你自己的域名。

```bash
sudo cp /opt/tier-board/deploy/nginx-tier-board.conf /etc/nginx/sites-available/tier-board
sudo ln -s /etc/nginx/sites-available/tier-board /etc/nginx/sites-enabled/tier-board
sudo nginx -t
sudo systemctl reload nginx
```

在云服务器防火墙和系统防火墙中开放 TCP 80 与 443，应用端口 3000 只监听本机，不需要向公网开放。

## 5. 配置域名与 HTTPS

在 DNS 服务商处添加 A 记录，把域名指向服务器公网 IPv4。解析生效后执行：

```bash
sudo certbot --nginx -d 你的域名
```

按照提示申请证书并启用 HTTP 到 HTTPS 跳转。最后访问 `https://你的域名/healthz` 和网站首页。

## 6. 更新应用

```bash
cd /opt/tier-board
sudo -u tierboard git pull
sudo -u tierboard npm ci
sudo -u tierboard npm run build
sudo systemctl restart tier-board
```

## 7. 备份与运维

- 定期备份 `/var/lib/tier-board`。
- 使用 `systemctl status tier-board` 查看运行状态。
- 使用 `journalctl -u tier-board -n 100` 查看最近日志。
- 使用 `certbot renew --dry-run` 检查证书自动续期。
- 不要公开 SQLite 文件、服务器密码或私钥。
