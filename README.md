# 夯拉板（Hangla Board）

[中文](README.md) · [English](README_EN.md) · [日本語](README_JA.md)

一个为视频创作者准备的 Tier List（分档榜单）工具。支持单机排序、干净录制、PNG 导出，以及通过房间号进行多人连线协作。

## 功能

- 一次上传或拖入多张图片
- 在待分档区和各档位之间拖动图片
- 默认提供“夯、顶级、人上人、NPC、拉完了”五档
- 新增、删除和重命名档位
- 拖动整行调整档位顺序
- 档位颜色固定在行位置，不随档位名称和内容移动
- 彩虹色与红橙黄白渐变两套主题
- 将最终分档结果导出为高清 PNG 图片
- 为每期排序命名，并用该标题命名导出的 PNG
- 创建或加入 8 位字母数字房间号，多人共同调整同一份排名
- 显示在线成员，房主可锁定最终排名或解锁继续讨论
- 联机房间中的图片、标题、主题和档位统一同步
- 干净录制模式：隐藏编辑控件，同时保留待分档素材栏
- 按 `Esc` 退出录制模式
- 单机模式的图片只在当前页面处理；联机房间的图片会上传到房间存储，供参与者共同查看

## 快速开始

只使用单机功能时，可以直接打开 `dist/index.html`。联机功能需要带数据库和图片存储的 Sites 部署环境。

1. 下载或克隆仓库。
2. 直接用浏览器打开 `dist/index.html`。

开发与构建：

```bash
npm install
npm run db:generate
npm test
```

`npm run build` 会生成可部署的 Worker。

## 使用方法

1. 点击“上传图片”，或直接把图片拖进页面。
2. 把待分档图片拖入对应档位。
3. 点击档位名称进行修改。
4. 使用档位右侧的拖动手柄调整整行顺序。
5. 点击看板标题，为这期排序取名。
6. 在顶部选择颜色主题。
7. 点击“导出图片”保存不含操作控件的最终榜单 PNG；图片标题和文件名都会使用排序名称。
8. 点击“联机房间”，填写昵称后创建房间，或输入他人的 8 位字母数字房间号加入（不区分大小写）。
9. 复制邀请链接发给连线嘉宾；所有人的调整会自动同步。
10. 大家确认后，由房主点击“锁定最终排名”；需要继续讨论时可以重新解锁。
11. 点击“干净录制”后开始录屏；录制时仍可继续分档。

## 当前限制

- 单机模式刷新后会清空；联机房间可在当前浏览器会话中自动恢复。
- 联机同步采用快速轮询，极短时间内同时操作同一位置时，以服务器收到的较新版本为准。
- 尚未提供视频导出。
- 主要针对桌面浏览器和录屏使用场景。
