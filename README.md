# 夯拉板（Hangla Board）

[中文](README.md) · [English](README_EN.md) · [日本語](README_JA.md)

一个为视频创作者准备的轻量 Tier List（分档榜单）工具。无需安装依赖，打开网页即可上传图片、拖动分档并进入干净录制模式。

## 功能

- 一次上传或拖入多张图片
- 在待分档区和各档位之间拖动图片
- 默认提供“夯、顶级、人上人、NPC、拉完了”五档
- 新增、删除和重命名档位
- 拖动整行调整档位顺序
- 档位颜色固定在行位置，不随档位名称和内容移动
- 彩虹色与红橙黄白渐变两套主题
- 将最终分档结果导出为高清 PNG 图片
- 为每期排序命名，并用该标题命名导出的 PNG
- 干净录制模式：隐藏编辑控件，同时保留待分档素材栏
- 按 `Esc` 退出录制模式
- 图片只在当前浏览器页面中处理，不会上传到服务器

## 快速开始

无需构建，也没有第三方依赖。

1. 下载或克隆仓库。
2. 直接用浏览器打开 `dist/index.html`。

也可以启动一个本地静态服务器：

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 `http://localhost:4173`。

## 使用方法

1. 点击“上传图片”，或直接把图片拖进页面。
2. 把待分档图片拖入对应档位。
3. 点击档位名称进行修改。
4. 使用档位右侧的拖动手柄调整整行顺序。
5. 点击看板标题，为这期排序取名。
6. 在顶部选择颜色主题。
7. 点击“导出图片”保存不含操作控件的最终榜单 PNG；图片标题和文件名都会使用排序名称。
8. 点击“干净录制”后开始录屏；录制时仍可继续分档。

## 当前限制

- 当前版本不会永久保存项目，刷新页面后图片和排序会清空。
- 尚未提供视频导出。
- 主要针对桌面浏览器和录屏使用场景。
